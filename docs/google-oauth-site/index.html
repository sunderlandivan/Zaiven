The PreEminent Store - Portal

Private inventory tool for The PreEminent Store (trading card games).

What it does

The PreEminent Store Portal is a private tool used only by the store owner. It reads order and sale confirmation emails (for example TCGplayer, Pokémon Center, Target and local game store receipts) and keeps the store's own Google Sheet inventory ledger up to date: it raises quantities when new stock is purchased and logs sales when items sell.

Google data it uses

  • Gmail (read-only): to read order and sale confirmation emails.
  • Google Sheets: to update the store's own inventory spreadsheet.

The portal runs on the owner's own computer. It is not offered to the public.
