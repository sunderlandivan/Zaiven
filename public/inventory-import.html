Import and Pricing

Load your inventory spreadsheet and refresh market prices.

Import inventory

No file selected

Pick your PreEminent export from your computer, then click Import Excel. Each spreadsheet row becomes one inventory line (same product name on multiple rows stays separate), including quantity 0 so out-of-stock lines match your file. If the workbook contains a sheet named FULL (any casing), only that sheet is imported; otherwise the first sheet is used. Expected columns include Item ID, Qty, Cost w/ Tax, and optional TCG Link. Re-importing replaces the list. Selling Analytics only lists rows with quantity ≥ 1.

Pricing scan

Rows with a TCG Link column use that URL only to resolve product and market price (no name search). Rows without a link still use marketplace search. Full refreshes can take several minutes for large inventories — the status line updates when finished.

Data reset tools

Use these only when needed. Inventory reset clears imported rows and sell workflow status. Orders reset clears order history only.
